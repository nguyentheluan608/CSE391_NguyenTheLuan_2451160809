Bootstrap Grid

Tại sao Bootstrap Grid giúp layout nhanh hơn?

Nguyễn Thế Luân • 20/05/2026 • 5 phút đọc

Bootstrap chia màn hình thành 12 cột nên việc tạo layout responsive trở nên dễ hơn. Khi cần 4 cột desktop và 1 cột mobile, chỉ cần dùng các class như col-12 col-md-6 col-lg-3.

Components Card

Dùng Card để trình bày bài viết và sản phẩm

Nguyễn Thế Luân • 22/05/2026 • 4 phút đọc

Card là component rất tiện để làm product card, blog post, profile card. Mình có thể kết hợp card-img-top, card-body, card-title và card-footer để giao diện rõ ràng.

Theme Customize

Tùy biến theme để giao diện không giống mặc định
